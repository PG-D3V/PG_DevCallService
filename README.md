## ✨ Features

- ✅ **One-to-One Video Calling**
- 🔄 **Random Video Calling**
- 📱 **Optimized for Sketchware Pro**
- ⚙️ **Simple & Quick Integration**
- 🔒 **Real-Time & Secure Communication**

---


## In Sketchware Pro: 
- manually copy the library source into your project blocks.

## Ensure permissions:
- ACCESS_NETWORK_STATE ( main permision for V2.0 )
- REGISTER_CALL_PROVIDER
- CAMERA
- RECORD_AUDIO
- MODIFY_AUDIO_SETTINGS
- MODIFY_AUDIO_ROUTING
- INTERNET

## 🚀 Getting Started
**🧰 Requirements**
- Android 5.0+ (API 21+ recommended)
- Sketchware Pro
